设计规则 13 rules
01Personal Risk OS first — 确定性 Account/Portfolio/Order/Trade Plan/Discipline/Market gates 先于 Agent 核心
02LLM only proposes — LLM 输出是提议；确定性域服务验证并提交最终状态
03Truth boundaries — PostgreSQL 存结构化持久真值；MinIO 存原始文件；pgvector/RAG 可重建；Redis 非真值
04Immutable history — Evidence/Thesis/Trade Plan/orders/fills/exits/discipline/alerts/rule versions 永不覆盖
05Fail closed — 缺失/过期/冲突/不可验证的决策关键数据禁止新风险
06Market before new stock risk — 冻结双指数 gate 先于个股准入；市场失败不自动卖出现有仓位
07Agent is read-only — 可读/解释/挑战/创建无副作用提议；不可提交订单/写事实/改阈值/清暂停
08User confirms trades — 系统不控制券商、不替代用户最终确认和计划亏损接受
09Maximum four stocks — 第五只需 Position Replacement PK 和实际容量释放
10Frozen model boundary — 不静默改变 v1.3 模型 / v1.1 系统 / Setup B / ActionDecision / 风险阈值 / 退出路径 / 恢复规则
11Strategy is UNPROVEN — 10/30/50 样本是审查门，不是盈利证明或提险许可
12Macro is staged — 告警表达脆弱性和压力；无确定性危机日期声明；单一宏观分数不自动清仓
13Version all policy changes — 生产规则变更需新版本/重放/前瞻验证/用户批准
